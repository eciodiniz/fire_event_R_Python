# fire_event_R_Python
Essa rotina permite gerar mapas de áreas de eventos de queimada usando ambos Python e R. Scripts disponíveis em português brasileiro e inglês.

-Nas pastas PT-BR e ENG você encontrará nas versões, respectivamente, em português brasileiro e inglês, as rotinas para procedimentos básicos para demonstrar áreas de ocorrência de queimadas usando as linguagens R e Python. O objetivo é meramente demonstrativo sobre como ambas as linguagens desempenham a mesma tarefa. 

-O script R está na extensão ".R" e pode ser aberto normalmente no RStudio ou como txt em alguma outra interface. O script Python está disponível em ambas as extensões de script ".py" e "ipynb" (para Jupyter Notebook).

ENGLISH:

This routine allows for the generation of maps of burned-area events using both Python and R. Scripts available in Brazilian Portuguese and English.

-In the PT-BR and ENG folders, you will find—in Brazilian Portuguese and English, respectively—routines for basic procedures to map areas affected by fires, using the R and Python programming languages. The objective is purely demonstrative, showing how both languages ​​can perform the same task.

-The R script uses the ".R" file extension and can be opened in RStudio, or as a text file in any other interface. The Python script is available in both ".py" and ".ipynb" (for Jupyter Notebook) formats.
